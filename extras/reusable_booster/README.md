# Reusable-booster landing example

Unmodified source snapshot from the Rumoca user guide, Apache-2.0; see
[provenance](provenance.json) and the repository [license](../../LICENSE).

For the workshop, [open the interactive guide](https://cognipilot.github.io/rumoca/user-guide/simulation/reusable-booster-landing.html).
Click the editor’s Run control, focus the scene and press **Space** to launch.
Use **Tune environment and controller** to change wind or deck motion; **R**
resets, **Q** stops. Inspect the Modelica and TOML tabs before changing one setting.

This is a reusable-booster teaching model, not a validated SpaceX Falcon 9
performance model. The copied scenario retains the upstream library path; it
requires the pinned library setup described in the guide for native execution.
Do not treat this snapshot as a zero-setup native demo.
